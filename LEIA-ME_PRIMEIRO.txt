BORION CNPJ 1.0.18 — CORREÇÃO DE LEITURA DO GOOGLE DRIVE

1. Não apague nenhuma pasta do Google Drive.
2. Extraia este ZIP para uma pasta normal do computador.
3. Para testar localmente, abra o arquivo index.html da pasta extraída. Não tente abrir o ZIP como se fosse uma pasta.
4. Para usar no celular/PWA, envie todo o conteúdo extraído para a raiz do mesmo repositório do GitHub Pages.
5. Aguarde a publicação terminar e confirme que a versão mostrada é 1.0.18.
6. Feche completamente o PWA antigo no celular e abra de novo.
7. Entre com a mesma conta Google usada no computador.

O que mudou:
- O ID configurado não trava mais o aplicativo em uma pasta específica.
- O Borion procura a base válida em todas as pastas Borion CNPJ acessíveis.
- Se existirem pastas Sistema/Dados duplicadas, escolhe a que contém os registros reais.
- Pastas vazias não vencem uma base com cheques.
- Nenhuma pasta ou arquivo é apagado durante a procura.
- A tela de entrada mostra apenas “CARREGANDO . . .”.

Fonte preferencial:
Borion CNPJ / Sistema / Dados / current.json

Arquivos compatíveis para recuperação:
- BORION_CNPJ_CURRENT.json
- current (1).json
- dados.json
- borion-cnpj-dados.json
- current.json.borion

IMPORTANTE
- Não limpe os dados do navegador do computador antes de confirmar que os cheques apareceram no celular.
- Não exclua pastas do Drive para “começar do zero”; isso pode eliminar a única cópia remota dos cheques e fotos.
