BORION CNPJ 1.0.3

1. Extraia o ZIP.
2. Abra js/config.js.
3. Cole o Google OAuth Client ID em googleClientId.
4. Envie todo o conteúdo extraído para a raiz do GitHub.
5. Ative o GitHub Pages.
6. Entre somente pelo botão Google.

A pasta Borion CNPJ será criada automaticamente no Drive da conta logada.
Não existe configuração manual de Client ID ou pasta dentro do aplicativo.
